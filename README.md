# ✨ To-Do List

Uma aplicação simples e elegante de lista de tarefas, criada com foco em **organização**, **experiência do usuário** e **estética minimalista**.

---

## 🌿 Sobre o projeto

Este projeto foi desenvolvido para praticar fundamentos de **Front-End**, utilizando HTML, CSS e JavaScript.
O objetivo é permitir que o usuário organize suas tarefas diárias de forma simples, leve e intuitiva.

---

## 🚀 Funcionalidades

* Adicionar novas tarefas  
* Marcar tarefas como concluídas  
* Remover tarefas  
* Persistência de dados utilizando **localStorage**  
* Animações suaves e microinterações  
* Design minimalista  

---

## 🎨 Layout & Experiência

* Interface clean e responsiva  
* Cores neutras e suaves  
* Animações CSS para entrada de elementos  
* Microinterações para melhorar a experiência do usuário  

---

## 🛠️ Tecnologias utilizadas

* **HTML5**  
* **CSS3** (animações, transições e efeitos visuais)  
* **JavaScript** (manipulação do DOM e localStorage)  
* **Git & GitHub**  
* **GitHub Pages** (deploy)
